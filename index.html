Quick Start

Beautiful by default. Instant to ship.

Glassmorphism, cinematic animations and a full design system in one stylesheet. No build step and no configuration: drop one line into any HTML page and start building.

  • 18.9 kB CSS, brotli
  • 7.5 kB optional JS
  • Zero dependencies
  • No build step

1. Add the stylesheet

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/DesvoSoft/Vitra@v1.14.1/dist/vitra.min.css" integrity="sha256-VqvCW9TWtiiiYglM8Ok1T1Y/tbXZ8sWvYvW7i/fPZko=" crossorigin="anonymous">

2. Add the script (optional: modals, drawers, tooltips, toasts, dropdowns, particles and theme persistence)

<script src="https://cdn.jsdelivr.net/gh/DesvoSoft/Vitra@v1.14.1/dist/vitra.min.js" integrity="sha256-XfDZdHFCtz3eXkyZ82L9abRDbp+yhwDFOvvsWNpqjFw=" crossorigin="anonymous" defer></script>

3. Use a component

<div class="vitra-card vitra-glass">Hello, Vitra!</div>

That's it. Full example:

<!DOCTYPE html>
<html data-theme="auto">
<head>
  <meta charset="UTF-8">
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/DesvoSoft/Vitra@v1.14.1/dist/vitra.min.css" integrity="sha256-VqvCW9TWtiiiYglM8Ok1T1Y/tbXZ8sWvYvW7i/fPZko=" crossorigin="anonymous">
</head>
<body>
  <div class="vitra-card vitra-glass">Hello, Vitra!</div>
  <script src="https://cdn.jsdelivr.net/gh/DesvoSoft/Vitra@v1.14.1/dist/vitra.min.js" integrity="sha256-XfDZdHFCtz3eXkyZ82L9abRDbp+yhwDFOvvsWNpqjFw=" crossorigin="anonymous" defer></script>
</body>
</html>

The integrity hash makes the browser refuse the file if it ever differs from the release. Using a bundler? Install from GitHub, pinned to the tag: npm install github:DesvoSoft/Vitra#v1.14.1. Vitra is not on the npm registry. More in the installation guide.

1.14 Every component, every theme, every input

Every component with state was checked against one contract: legible in all seven themes and in auto under a light and a dark system, usable from the keyboard with a visible focus ring, 44 px touch targets, and content that shows without JavaScript.

A real drawer

Vitra.drawer links a toggle to a .vitra-drawer: overlay, Esc, a focus trap, focus return, scroll lock and inert while closed. This site's mobile menu is one.

Esc now closes one layer at a time: a tooltip, then a menu, then the drawer or modal around it.

Menus from the keyboard

Focus the button and press ↓: the menu opens on its first item. Arrow keys, Home and End move, Esc closes it and returns to the button, Tab closes it and moves on.

Contrast in every theme

Text reaches 4.5:1 and control borders 3:1 (the new --vitra-color-border-control token) in every theme, and auto now matches light or dark exactly. Pick one: it grows out of the button you pressed.

Motion off the main thread

The striped progress bar and the indeterminate ring now animate transform, so they no longer repaint every frame, and every infinite loop pauses while it is offscreen.

CSS in pieces

The bundle is also built as three pieces, so a page without scenery or effects can leave them out. Load order does not matter.

vitra.core.min.css
13.0 kB
vitra.scenery.min.css
5.0 kB
vitra.effects.min.css
2.3 kB

Brotli. scenery and effects need core; all three (20.3 kB) cost more than the 18.9 kB bundle, so use them to leave one out.

Named imports

An ES module with one export per module, a CommonJS build and TypeScript types. Install from GitHub: Vitra is not on the npm registry.

npm install \
  github:DesvoSoft/Vitra#v1.14.1

import { theme, drawer } from 'vitra-css';
drawer.open('#menu');

Importing still runs the auto-init, so the package is not side-effect free.

Scenery

A CSS-only mountain landscape. Faceted ranges with light-facing planes over a still, dark foreground, a star field that shimmers against a steady far plane, a moon whose corona breathes. It fades up when it enters the screen, separates into depth planes as it scrolls away, and re-colours itself from the theme's accent.

A window, not a card This scene is one empty div. The mountains, clouds, and stars all drift behind this glass at different speeds — same direction, so it reads as one consistent wind. Switch themes — the whole scene re-colors itself.

Markup

One element. With vitra.js on the page the eight layers are written for you; use .vitra-scenery for a full-page backdrop or .vitra-scenery-inline inside any position: relative container. No JavaScript? The docs have the eight-layer markup — the scene itself is pure CSS.

<div class="vitra-scenery"></div>

Direct it with tokens:

.hero {
  --vitra-scenery-intro: 1.5;   /* entrance fade length, 0 = none */
  --vitra-scenery-depth: 1;     /* scroll parallax strength */
  --vitra-scenery-speed: 1;     /* drift speed */
  --vitra-scenery-halo-x: 76%;  /* moon position */
}

Data-Attribute Particles

Particles can also be configured via HTML data-vitra-particles attributes:

<div data-vitra-particles="5" data-vitra-particle-color="#ff6b6b">
  <!-- 5 red particles appear here -->
</div>

<!-- opt-in falling direction -->
<div data-vitra-particles="8" data-vitra-particle-direction="down">
  <!-- 8 particles fade in and drift downward, then fade out -->
</div>
